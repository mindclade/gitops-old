# Release metadata

Release records are generated by `mindclade-internal-monorepo` and enter this repository only
through reviewed promotion pull requests. Each `*.json` record uses contract `3.0.0` and binds
one immutable image digest to its full source SHA, builder identity and invocation, checksummed
SBOM and provenance artifacts, passing vulnerability and qualification evidence, the distinct
Buildkite build and qualification attestor roots, and the protected GitHub deployment attestor
and immutable signer workflow identity.

GitOps does not manufacture missing evidence. `provenance.yml` verifies the candidate records
before checking the external deployment attestation, and production reconciliation references
only image digests with complete evidence. The deployment attestation is the runtime trust root:
its dedicated signer can create it only after verifying independent Buildkite build/provenance
and qualification occurrences. GitOps cannot create any of those attestations.
