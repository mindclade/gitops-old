# Release metadata

Release records are generated by `mindclade-internal-monorepo` and enter this repository only
through reviewed promotion pull requests. Each `*.json` record uses contract `2.0.0` and binds
one immutable image digest to its full source SHA, builder identity and invocation, checksummed
SBOM and provenance artifacts, passing vulnerability and qualification evidence, the GitHub
attestation signer identity, and the Binary Authorization attestor/project.

GitOps does not manufacture missing evidence. `provenance.yml` verifies the candidate records
before checking the external attestations, and production reconciliation references only image
digests with complete evidence.
