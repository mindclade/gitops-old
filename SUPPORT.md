## Routing

| Need | Route |
| --- | --- |
| Desired-state, policy, or documentation defect | Open a sanitized issue in this repository |
| Planned GitOps change | Open a pull request with evidence required by [CONTRIBUTING.md](CONTRIBUTING.md) |
| Failed synchronization | Follow [docs/failed-sync.md](docs/failed-sync.md) |
| Rollback or emergency freeze | Follow [docs/rollback.md](docs/rollback.md) or [docs/freeze-and-emergency.md](docs/freeze-and-emergency.md) |
| Security, admission bypass, or unsigned-image concern | Follow [SECURITY.md](SECURITY.md); never open an issue |
| Cloud-resource problem | Route to `mindclade/infrastructure-live` |
| Contractual customer support | Use the channel and service terms in the applicable agreement |

GitHub issues do not carry an SLA. Do not include credentials, plaintext
secrets, customer data, model weights, restricted biological content, private
cluster evidence, or incident-sensitive material. Use sanitized application,
revision, run, release, and artifact identifiers.

The applicable customer agreement or incident-response process controls if it
conflicts with this routing guide.
